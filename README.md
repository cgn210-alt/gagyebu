# 생활 가계부

급여 등 수입, 생활비 지출, 저축, 대출 상환, 매달 고정 항목, 월 예산을 한곳에서 관리하는 개인 가계부입니다.

- 주소(예정): https://cgn210-alt.github.io/gagyebu/
- 저장: Firebase Realtime Database (`ledger` 경로), 개인 재정 자료이므로 별도 Firebase 프로젝트 사용
- 접근: 구글 로그인, `firebase-config.js`의 `OWNER_EMAIL` 계정 한 개만
- Firebase 설정 전에는 "이 기기에만 저장" 모드로 쓸 수 있습니다 (브라우저에만 저장)

## 화면

- 홈: 이번 달 수입·지출·저축·대출상환과 남은 돈, 저축·대출 잔액과 순자산, 분류별 지출과 예산 사용률, 최근 6개월 추이. 고정 항목이 아직 내역에 없으면 "반영하기"로 한 번에 추가.
- 내역: 월별 내역을 날짜별로 보기, 구분별 걸러 보기, 메모 검색. 눌러서 수정·삭제.
- 저축: 저축 통장(시작 잔액, 매달 금액, 목표, 만기) 등록. 잔액은 입출금 기록으로 자동 계산.
- 대출: 대출 잔액·상환률, 이번 달 상환액과 완료 건수, 올해 낸 이자·갚은 원금. 달마다 대출별 상환 체크(완료·예정·상환일 지남)와 금리 변동일 알림. 대출을 누르면 상세 정보(유형, 금리 방식, 기준금리, 상환 방식, 거치기간, 상환일, 출금 계좌, 중도상환수수료), 앞으로의 상환 스케줄표, 상환 이력, 금리 변경 이력.
- 고정·예산: 급여·관리비·보험료·적금·대출 상환 같은 매달 항목, 지출 분류별 월 예산.
- 설정: 수입·지출 분류와 결제 수단 편집, 엑셀(CSV) 내보내기, 백업 파일(JSON) 내려받기·복원.

대출 이자는 "남은 원금 × 연 이자율 ÷ 12"로 계산한 예상치입니다. 실제 은행 금액과 다르면 상환 기록 때 고쳐 넣으면 됩니다.

## 처음 설정 (한 번만)

1. https://console.firebase.google.com 에서 새 프로젝트 만들기 (예: `gagyebu`)
2. Build > Realtime Database > 데이터베이스 만들기 (위치: 싱가포르, 잠금 모드)
3. Realtime Database > 규칙 탭에 `database.rules.json` 내용을 붙여 넣고 게시
4. Build > Authentication > 시작하기 > 로그인 방법 > Google 사용 설정
5. Authentication > 설정 > 승인된 도메인에 `cgn210-alt.github.io` 추가
6. 프로젝트 설정 > 내 앱 > 웹 앱 추가 → 나오는 설정값을 `firebase-config.js`에 붙여 넣기
7. GitHub에 `gagyebu` 저장소를 만들고 이 폴더를 올린 뒤, Settings > Pages 에서 main 브랜치 배포

`OWNER_EMAIL`을 바꾸려면 `firebase-config.js`와 `database.rules.json` 두 곳을 모두 고치고, 규칙을 Firebase 콘솔에 다시 게시해야 합니다.

"이 기기에만 저장" 모드로 먼저 쓰던 내용은 설정 탭에서 백업 파일을 내려받은 뒤, 로그인 후 "백업 파일로 복원"하면 옮겨집니다.
